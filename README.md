# SkillHub

**SkillHub** — мини-биржа услуг для школьников и студентов, написанная на Python с графическим интерфейсом на Tkinter.

Подростку трудно найти первые заказы на больших биржах фриланса: нет опыта и отзывов. В SkillHub школьники могут предложить то, что они умеют: сделать логотип, помочь с английским, смонтировать видео или объяснить математику. Другие пользователи быстро находят подходящего исполнителя, смотрят его рейтинг и отзывы и заказывают услугу.

## Возможности

1. **Современный интерфейс**: градиентная шапка, карточки со скруглёнными углами и тенью, цветные метки категорий, аватары исполнителей.
2. **Каталог услуг** в виде карточек: категория, название, описание, исполнитель, цена и рейтинг.
3. **Поиск** по названию, описанию и имени исполнителя.
4. **Фильтр по категориям** в виде кнопок-«чипсов»: Дизайн, Программирование, Языки, Видео, Учёба, Другое, а также «Мои услуги».
5. **Сортировка**: сначала новые, сначала дешёвые, сначала дорогие, по рейтингу.
6. **Рейтинг и отзывы**: оценка от 1 до 5 звёзд и текст отзыва. Средний рейтинг показывается прямо в карточке услуги.
7. **Добавление своей услуги** через форму с проверкой введённых данных.
8. **Удаление только своего**: услугу и отзыв может удалить лишь тот, кто их добавил. Заказы можно удалять из своего списка. Каждое удаление требует подтверждения.
9. **Оформление заказа** и получение контакта исполнителя.
10. **Список заказов** с общей суммой, можно сразу оставить отзыв на заказанную услугу.
11. **Автоматическое сохранение** всех данных в файл `skillhub_data.json`.

### Правила удаления

- Удалить услугу можно только если ты сам её добавил. У чужих и демонстрационных услуг кнопки «Удалить» нет, а у твоих появляется метка «Моя услуга».
- Отзыв можно удалить только свой. Кнопка «Удалить мой отзыв» показывается только под твоими отзывами.
- Свою услугу нельзя заказать и нельзя оценить, чтобы не накручивать рейтинг.
- Фильтр «Мои услуги» показывает только добавленные тобой услуги.

Как это работает: при первом запуске программа создаёт случайный идентификатор пользователя `user_id` и сохраняет его в `skillhub_data.json`. Услуги и отзывы, которые ты добавляешь, помечаются этим идентификатором (`owner_id`), и только по нему разрешается удаление. Система аккаунтов (логин и пароль) пока не реализована: «владелец» — это тот, у кого этот файл данных. Полноценная защита появится вместе с регистрацией пользователей (см. планы развития).

### Правила отзывов

- Оценка обязательна (1–5 звёзд), текст отзыва — не короче 3 символов.
- С одним и тем же именем можно оставить только один отзыв на услугу.
- Оставить отзыв можно на любую услугу, кроме своей.
- Средний рейтинг = сумма оценок / количество отзывов (показывается с одним знаком после запятой).
- При удалении услуги удаляются и её отзывы. Заказы остаются в истории.

## Установка и запуск

### Шаг 1. Установите Python

Нужен Python версии 3.8 или новее. Проверьте, установлен ли он, открыв командную строку (терминал):

```
python --version
```

На macOS и Linux команда может называться `python3`. Если Python не установлен, скачайте его с [python.org/downloads](https://www.python.org/downloads/).

> **Windows:** при установке обязательно поставьте галочку **Add Python to PATH** и не убирайте компонент **tcl/tk and IDLE** — в нём находится Tkinter.

### Шаг 2. Скачайте проект

**Вариант А — через Git:**

```
git clone https://github.com/ВАШ_ЛОГИН/skillhub.git
cd skillhub
```

**Вариант Б — без Git:** на странице репозитория нажмите зелёную кнопку **Code → Download ZIP**, распакуйте архив и откройте папку проекта в командной строке.

### Шаг 3. Запустите программу

```
python main.py
```

(на macOS / Linux: `python3 main.py`)

При первом запуске автоматически создастся файл `skillhub_data.json` с примерами услуг и отзывов.

### Установка Tkinter на Linux

Если при запуске появляется ошибка `No module named 'tkinter'`, установите пакет:

```
# Ubuntu / Debian
sudo apt install python3-tk

# Fedora
sudo dnf install python3-tkinter
```

### Сбросить данные

Закройте программу и удалите файл `skillhub_data.json`. При следующем запуске программа создаст его заново с примерами.

## Как пользоваться

### Найти услугу
1. На главном экране введите слово в поле **Поиск** — список обновляется сразу.
2. Нажмите на кнопку нужной **категории** и выберите способ **сортировки**, чтобы сузить список.

### Заказать услугу
1. Нажмите **Заказать** в карточке нужной услуги.
2. Введите своё имя.
3. Программа покажет контакт исполнителя (Telegram) — напишите ему и договоритесь о деталях.

### Посмотреть отзывы и оставить свой
1. Нажмите **Отзывы** в карточке (или кликните по звёздам).
2. Внизу окна введите имя, поставьте оценку кликом по звёздам, напишите текст и нажмите **Отправить отзыв**.
3. Свой отзыв можно удалить кнопкой **Удалить мой отзыв**. Чужие отзывы удалить нельзя.

### Добавить свою услугу
1. Нажмите **+ Добавить услугу** в правом верхнем углу.
2. Заполните все поля: название, категорию, цену (только цифры), имя и возраст, контакт, описание.
3. Нажмите **Опубликовать** — карточка появится в начале списка.

### Удалить услугу
Кнопка **Удалить** есть только у ваших собственных услуг (с меткой «Моя услуга»). Нажмите её и подтвердите действие. Вместе с услугой удалятся её отзывы. Чтобы быстро найти свои услуги, выберите фильтр **Мои услуги**.

### Мои заказы
1. Нажмите **Мои заказы** в шапке.
2. В таблице видны все заказы и общая сумма.
3. Выберите заказ и нажмите **Оставить отзыв** или **Удалить заказ**.

## Как устроена программа

Код разделён на слои, чтобы каждый файл отвечал за что-то одно:

| Файл | За что отвечает |
|------|-----------------|
| `config.py` | Все настройки в одном месте: цветовая палитра, градиент, шрифт, список категорий, лимиты длины полей. Чтобы поменять дизайн или добавить категорию, достаточно изменить этот файл. |
| `database.py` | Вся логика работы с данными: загрузка и сохранение JSON, добавление и удаление услуг, отзывов и заказов, расчёт среднего рейтинга, поиск и сортировка, проверка форм. Не зависит от Tkinter, поэтому покрыт тестами. |
| `widgets.py` | Элементы интерфейса: скруглённые кнопки и метки, карточки с тенью `RoundedCard`, градиентная шапка `GradientBar`, выбор звёзд, прокручиваемый список. |
| `dialogs.py` | Дополнительные окна: `AddServiceDialog`, `ReviewsDialog`, `OrdersDialog`. |
| `app.py` | Класс `SkillHub` — главное окно, которое собирает всё вместе. |
| `main.py` | Запускает приложение. |

Особенности реализации:

- Каждая услуга и заказ получают уникальный `id`, поэтому удаление и отзывы привязаны к конкретной записи, а не к названию.
- Права на удаление проверяются в `database.py` (`is_owner`, `can_delete_review`), а не только в интерфейсе: даже если кнопка была бы показана по ошибке, чужую запись удалить нельзя.
- Данные сохраняются через временный файл, поэтому при сбое запись не ломает основной файл.
- Если `skillhub_data.json` повреждён, программа сохраняет его копию как `skillhub_data.json.broken` и запускается с примерами.
- Файл данных от старой версии программы (без отзывов и `id`) обновляется автоматически при загрузке.

## Тесты

Тесты проверяют логику: рейтинг, отзывы, удаление, фильтры, сохранение и загрузку данных. Запуск из корня проекта:

```
python -m unittest discover tests
```

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| `python` не найден | Переустановите Python с галочкой **Add Python to PATH** или используйте `python3` / `py`. |
| `No module named 'tkinter'` | На Linux: `sudo apt install python3-tk`. На Windows переустановите Python и оставьте компонент tcl/tk. |
| Русские буквы отображаются неправильно | Запускайте программу из папки проекта; файл данных всегда читается в UTF-8. |
| Хочу начать с чистыми данными | Удалите `skillhub_data.json` и запустите программу снова. |
| «Не удалось сохранить данные» | Проверьте, что у папки проекта есть права на запись. |
