# SkillHub

SkillHub - это мини-биржа услуг для школьников и студентов, написанная на Python.

Подростку трудно найти первые заказы на больших биржах фриланса, потому что нет опыта и отзывов. В SkillHub школьники могут предложить то, что они умеют: сделать логотип, помочь с английским, смонтировать видео или объяснить математику. А другие пользователи могут быстро найти подходящего исполнителя.

## Возможности

1. Просмотр услуг в виде карточек: название, категория, описание, исполнитель и цена.
2. Поиск услуг по тексту.
3. Фильтр по категориям: Дизайн, Программирование, Языки, Видео, Учёба, Другое.
4. Добавление своей услуги через форму с проверкой введённых данных.
5. Удаление услуги с подтверждением.
6. Оформление заказа и получение контакта исполнителя.
7. Список заказов с общей суммой.
8. Автоматическое сохранение данных в файл skillhub_data.json.

## Технологии

1. Python 3
2. Tkinter для создания интерфейса
3. JSON для хранения данных

## Как запустить

1. Скачайте файл skillhub.py из этого репозитория.
2. Откройте командную строку в папке с файлом и введите команду: python skillhub.py

Устанавливать дополнительные библиотеки не нужно, так как Tkinter уже входит в состав Python.

## Как пользоваться

1. На главном экране просмотрите список услуг. Для удобства используйте поиск и выбор категории.
2. Чтобы заказать услугу, нажмите кнопку "Заказать", введите своё имя и получите контакт исполнителя.
3. Чтобы предложить свою услугу, нажмите "+ Добавить услугу" и заполните все поля формы.
4. Чтобы посмотреть оформленные заказы, нажмите "Мои заказы".

## Файлы проекта

1. skillhub.py - основная программа
2. skillhub_data.json - файл с данными, создаётся автоматически при первом запуске
